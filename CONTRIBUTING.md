# Contributing to Portfolio Impact Bot

Thank you for your interest in contributing! We welcome contributions from everyone.

## 🐛 Reporting Bugs

If you find a bug, please create an issue on GitHub. Include as much detail as possible:
-   A clear description of the problem.
-   Steps to reproduce the issue.
-   Your n8n version and database type.
-   Any error logs from n8n or the database.

## ✨ Suggesting Features

We love new ideas! If you have a suggestion:
1.  Check the existing issues to see if it has already been proposed.
2.  Open a new issue describing the feature and why it would be useful.

## 🛠 Pull Requests

1.  Fork the repository.
2.  Create a new branch for your feature or bugfix.
3.  Ensure your changes follow the project's style and patterns.
4.  Update the documentation if necessary.
5.  Submit a pull request with a clear description of your changes.

## 📜 Code of Conduct

Please be respectful and professional in all interactions within this project.
